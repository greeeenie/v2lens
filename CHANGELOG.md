# Changelog

## 0.2.1 — 2026-10-17

- Нажатие на троеточие раскрывает свёрнутый JSON-блок с первого раза, не перемещая каретку и не меняя текст.
- Кнопка добавления значения скрыта на заголовке свёрнутого блока; раскрытие доступно также с клавиатуры.
- Убрана надпись «Empty template · v2rayN defaults».

## 0.2.0 — 2026-10-17

- Переключатель TUN / Without TUN: раздельные чтение, проверка штатным Xray и сохранение полей TunConfig / Config.
- Независимые черновики, история отмены, конфликты и свёрнутые блоки; предупреждение при закрытии с несохранённым черновиком другого режима.
- Авторелоад только для текущего режима; сохранение второго шаблона не переключает TUN.
- Изменение размера окна за края и углы, с минимальным размером 690 × 450.

## 0.1.0 — 2026-10-17

- Минималистичный просмотр соединений Xray: приложение, PID, TCP/UDP, адрес, Proxy/Direct и скорость трафика.
- Поиск, фильтры маршрута, сортировка и раскрываемая группировка по приложению.
- Плоское раскрытие приложения сразу до соединений с PID, без промежуточных строк процесса.
- Отдельный сортируемый столбец Gateway (TUN / SOCKS); входы и их счётчики не смешиваются.
- JSON-редактор полного TUN-шаблона v2rayN: подсветка, сворачивание, Format, Expand all и добавление значений по типу соседнего элемента.
- Сохранение свёрнутых блоков и настроек интерфейса между запусками.
- Проверка конфигурации штатным Xray перед сохранением; защита от перезаписи чужих параллельных изменений.
- Опциональный Auto-reload v2rayN после сохранения с подтверждением смены процесса Xray.
- Переносимый Windows x64 EXE со встроенными Python, редактором и ETW-помощником.
- Короткие README на английском и русском с переключением языка; исходники, интерфейс и сборка разнесены по папкам.
