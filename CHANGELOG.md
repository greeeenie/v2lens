# Changelog

## 0.1.0 — 2026-10-17

- Минималистичный просмотр соединений Xray: приложение, PID, TCP/UDP, адрес, Proxy/Direct и скорость трафика.
- Поиск, фильтры маршрута, сортировка и раскрываемая группировка по приложению.
- JSON-редактор полного TUN-шаблона v2rayN: подсветка, сворачивание, Format, Expand all и добавление значений по типу соседнего элемента.
- Сохранение свёрнутых блоков и настроек интерфейса между запусками.
- Проверка конфигурации штатным Xray перед сохранением; защита от перезаписи чужих параллельных изменений.
- Опциональный Auto-reload v2rayN после сохранения с подтверждением смены процесса Xray.
- Переносимый Windows x64 EXE со встроенными Python, редактором и ETW-помощником.
